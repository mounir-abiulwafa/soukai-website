Guides anti-arnaque

Faux message bancaire : repérer une arnaque.

Un message seul ne prouve pas qu’il vient de votre banque. Vérifiez dans l’application ou avec un numéro officiel.

Signaux d’alerte

Demande de code unique, mot de passe ou transfert d’argent pour « protéger » le compte.

Étapes sûres

N’utilisez ni le lien ni le numéro du message ; ouvrez l’application bancaire ou appelez le numéro de votre carte.
